**Description**

```
Prompt Vault saves your AI chat conversations as files on your own computer, so you keep a
copy that doesn't depend on an account or a server. No sign-up, no cloud, no data leaving
your browser.

Open a conversation on ChatGPT, Claude, or Gemini and export buttons appear in the page
header. One click saves what you're reading, in the format you pick:

• Markdown (.md) — plain, portable text with headings and code blocks intact
• PDF (.pdf) — selectable text, with Korean and other CJK glyphs and monospace code blocks
• JSON (.json) — structured data you can hand to other tools
• HTML (.html) — a self-contained page that opens in any browser

Need more than one conversation at a time? Open the bulk-export panel, tick the ones you
want, and save the whole set in one format and one run. It works from the sidebar on
ChatGPT, Claude, and Gemini; from a project's conversation list on ChatGPT and Claude; and
on Claude, from the full history page at claude.ai/recents.

Key points:
• 100% local. The extension talks to no server and sends nothing off your device. Your
  conversations never leave your browser.
• Least privilege. It runs only on ChatGPT (chatgpt.com), Claude (claude.ai) and Gemini
  (gemini.google.com), and asks for the minimum permissions those need.
• Fails loud. When a conversation can't be read properly, you get an error message instead
  of a half-empty file in your downloads folder.
• Your toolbar, your call. The extension popup shows or hides each export format icon and
  the bulk-export icon.
• The interface is in English, Korean, Japanese, Simplified Chinese and Traditional
  Chinese, and follows your browser language.

Supported sites: ChatGPT, Claude and Gemini. Bulk export works on all three; project export
works on ChatGPT and Claude.
```
