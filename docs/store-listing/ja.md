
**Description**

```
Prompt Vault は、AI との会話を自分のパソコンにファイルとして残す拡張機能です。アカウントも
クラウドも要らず、会話の内容がブラウザの外に出ることもありません。

ChatGPT、Claude、Gemini で会話を開くと、ページの上部にエクスポートのボタンが並びます。形式を
選んで押せば、いま読んでいる会話がそのままファイルになります。

• Markdown (.md) — 見出しもコードブロックもそのままの、扱いやすいテキスト
• PDF (.pdf) — 文字は選択もコピーもでき、日本語の字形もコードの等幅も崩れません
• JSON (.json) — 別のツールにそのまま渡せる構造化データ
• HTML (.html) — 1 ファイルで完結し、どのブラウザでも開けるページ

まとめて残したいときは、一括エクスポートのパネルを開き、必要な会話にチェックを入れて形式を
ひとつ選びます。ChatGPT、Claude、Gemini はいずれもサイドバーから、ChatGPT と Claude は
プロジェクトの会話一覧からも、Claude は全履歴ページ（claude.ai/recents）からも使えます。

こだわった点:
• 処理はすべて手元で。ネットワークリクエストは一切行わず、どのサーバーにも送信しません。
• 権限は最小限。ChatGPT（chatgpt.com）、Claude（claude.ai）、Gemini（gemini.google.com）
  の 3 サイトでのみ動きます。
• 読み取りに失敗したときは、中身の欠けたファイルを残さずエラーを表示します。
• ツールバーは自分好みに。拡張機能のポップアップで、各形式のアイコンと一括エクスポートの
  アイコンを個別に表示・非表示にできます。
• 表示言語は英語・日本語・韓国語・中国語（簡体字・繁体字）の 5 つ。ブラウザの言語に従います。

対応サイトは ChatGPT、Claude、Gemini です。一括エクスポートは 3 サイトすべてで、プロジェクト
単位のエクスポートは ChatGPT と Claude で使えます。
```
